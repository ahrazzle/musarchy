Setup guide

Get your laptop on Muse.

About ten minutes: a token, one installer, one pairing step in the app.

What you need

  • A laptop running Omarchy 4 (Arch-based), with Bluetooth.
  • Internet on the laptop, and sudo access.
  • The Muse app on your phone.
  • An SDK token from gadgets.muse.ai (Account → SDK tokens). Read the Gadget SDK Terms there first.

1. Run the installer

On the Omarchy laptop:

curl -fsSL https://raw.githubusercontent.com/ahrazzle/musarchy/main/install.sh -o install.sh
less install.sh   # read it first
bash install.sh --sdk-token mgst_...

The installer adds the needed packages with pacman, installs the device agent and the musarchy plugin, creates a locked-down muse account, starts the service, and opens Bluetooth pairing for 10 minutes. It prints the Bluetooth device name — it looks like MuseGadgetXXXXXX.

2. Pair in the Muse app

  1. In the Muse app, turn on Settings → Devices → Developer mode.
  2. Add Device (the + icon) and choose the MuseGadgetXXXXXX name the installer printed.
  3. The app warns this is a community device. Continue if it is yours.
  4. When asked for Wi-Fi, pick the network shown. The laptop is already online, so no password is needed.

Done. The device stays connected across reboots. To open pairing again later, run sudo musegadget pair on the laptop.

3. Try it

Ask your Muse things like:

  • “What windows do I have open on my laptop?”
  • “How much disk space is free?”
  • “Show a notification on my screen that says the backup finished.”

One decision: whose files?

By default your Muse runs as the muse account — no sudo, no access to your personal files. Safe starting point. If you want it managing your stuff (your home directory, your projects), reinstall with:

bash install.sh --sdk-token mgst_... --run-as YOUR_USERNAME

More useful, more trust. The installer warns you when the account has sudo.

Troubleshooting

  • No Bluetooth adapter warning during install. Pairing needs Bluetooth LE. It cannot work until an adapter is present.
  • Pairing window expired. Run sudo musegadget pair to open it again.
  • iPhone shows a generic connection error. Toggle the phone's Bluetooth off and on, then try again.
  • Something failed. The service log tells the story: sudo journalctl -u musegadget -f. Open an issue on GitHub with what you see — this installer is new and your report helps.
