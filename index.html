Omarchy × Muse

Your laptop,
reachable from your Muse.

Musarchy installs Meta's open-source Muse device agent on an Omarchy laptop and adds Hyprland-aware commands. Pair once in the Muse app, then ask your Muse to run commands, move files, check on the machine, list your windows, or show notifications — from your phone.

Alpha. The installer is new and untested on live hardware — see the setup guide.

How it works

  1. Install Omarchy 4 on the laptop, from the official ISO.
  2. Run the musarchy installer. It ports the device agent to Arch, creates a locked-down muse account, and starts the service.
  3. Pair in the Muse app. Settings → Devices → Developer mode → Add Device. It reconnects on its own after reboots.

What your Muse can do

CommandWhat it does
system.runRun a shell command, get stdout, stderr, exit code
file.read / file.writeRead and write files in chunks
device.healthUptime, load, memory, disk, temperature
desktop.runRun a command inside your graphical Hyprland session
desktop.windowsList open windows: app, title, workspace, focus
desktop.notifyShow a desktop notification on your screen

Built on open source, not a fork

Musarchy is a layer, not a fork. Omarchy stays stock, Meta's device SDK stays pinned to an upstream commit, and musarchy is the glue between them: an Arch-ported installer, a plugin that adds the desktop commands, and a hardened service setup. Upgrading either side is a version bump, not a rebase.

Security in one paragraph

Your Muse gets the permissions of the muse account: no sudo, no password login, no access to your files. There is no command allowlist — if you ask it to do something destructive as that account, it can. Pair on a network you trust. The full model is in docs/SECURITY.md.
